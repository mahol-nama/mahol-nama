# Monitoring of Urban Greenery

- [Continuous Monitoring and Ranking of Urban Parks in Karachi based on Greenspace Change](https://ee-mdfarooqui37.projects.earthengine.app/view/geospatial-urban-greenspace-change-monitoring-period-wise-ka)  
This app allows the user to contiuously monitor urban parks in Karachi and rank them based on greenspace change over a span 6 months, 1 year, or 5 years. The user can also evaluate each park individually for detailed statistics about greenspace change. 
- [Greenery in Karachi Parks: Change Analysis over Fixed Time Intervals](https://ee-mdfarooqui37.projects.earthengine.app/view/continuous-urban-greenspace-monitoring-period-wise-karachi-p)  
This app allows the user to choose a park in Karachi and analyze the change in greenery over last 6 months, last year, or last 5 years.   
- [Greenery in Karachi Parks: Change Analysis over Customized Time Intervals](https://ee-mdfarooqui37.projects.earthengine.app/view/continuous-greenspace-monitoring-datewise-karachi-parks)  
This app allows the user to choose a park in Karachi and compare the greenery between any two months since 2018.  
- [Urban Greenery in Karachi Neighborhoods: Change Analysis over Fixed Time Intervals](https://ee-mdfarooqui37.projects.earthengine.app/view/continuous-urban-greenspace-monitoring-period-wise-karachi-n)  
This app allows the user to choose a neighborhood in Karachi and analyze the change in urban greenery over last 6 months, last year, or last 5 years.  
- [Urban Greenery in Karachi Neighborhoods: Change Analysis over Customized Time Intervals](https://ee-mdfarooqui37.projects.earthengine.app/view/continuous-urban-greenspace-monitoring-date-wise-karachi-nei)  
This app allows the user to choose a neighborhood in Karachi and compare the urban greenery between any two months since 2018.
