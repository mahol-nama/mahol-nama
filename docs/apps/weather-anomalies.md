# Monitoring of Weather Anomalies

- [District-Level Weather Anomalies in Pakistan: Historical Pattern Analysis](https://ee-mustafaasghar66.projects.earthengine.app/view/districtleveltemperaturerainfallanalysis)  
This app supports historical pattern analysis of district-wise weather anomalies in Pakistan using ERA5 data.
- [District-Level Weather Anomalies in Pakistan: Near Real-Time Monitoring](https://ee-mustafaasghar66.projects.earthengine.app/view/updatednearrealtime)  
This app supports near real-time monitoring of district-wise weather anomalies in Pakistan using ERA5 data.  
- [District-Level Weather Anomalies in Pakistan: Forecast](https://ee-mustafaasghar66.projects.earthengine.app/view/gfsforecastvshistorical)  
This app compares 16-day weather forecast with the historical averages for the same 16-day period in order to identify the upcoming district-wise weather anomalies in Pakistan.
